Splynx

Splines built for fast lookups. There are three kinds:

Kind Made by Shape Editable
LinearSpline Splynx.linear Straight segments between the points Yes
CubicSpline Splynx.bezier, Splynx.hermite, Splynx.cardinal, Splynx.catmullRom, Splynx.bSpline Smooth curves Yes
SampledSpline Splynx.sampled Straight segments a fixed distance apart along another spline No

Lookups are prioritised over edits: everything that speeds up a lookup is precomputed, and rebuilt when the spline changes. Run lune run bench for current numbers.

Points and the pivot

Points are relative to the spline's pivot, and every position a spline returns has the pivot applied. Moving the pivot moves the whole spline without rebuilding anything.

Alpha and distance

getPos(alpha) splits alpha evenly across a spline's curves, so it speeds up and slows down along curves of different lengths. For a constant speed, work in distances: getPosAtDistance, getUniformPos and sampleUniform.

Hints

Distance lookups take an optional hint and return a new one. Passing back the previous call's hint starts the next lookup where the last one ended, which makes lookups for something moving along the spline cheaper. Any hint gives the same result, so a stale one is fine; leave it out for lookups that jump around. 

local spline = Splynx.catmullRom({ Vector3.new(0, 0, 0), Vector3.new(10, 5, 0), Vector3.new(20, 0, 0) })

local distance, hint = 0, nil
RunService.Heartbeat:Connect(function(deltaTime)
    distance = (distance + 12 * deltaTime) % spline:getLength()
    local position
    position, hint = spline:getPosAtDistance(distance, hint)
    part.Position = position
end)

Vectors

Inputs accept Vector3 or vector, and outputs are vector. On Roblox the two are the same value, but the type checker treats them as different types, so outputs may need a cast where a Vector3 is expected.

Functions​

linear​

</>
Splynx.linear(
points: {VectorLike}?,--

Relative to the pivot.

pivot: VectorLike?--

Defaults to the origin.

) → LinearSpline

Straight segments between the points. Needs at least two points to make a segment.

bezier​

</>
Splynx.bezier(
points: {VectorLike}?,--

Relative to the pivot.

pivot: VectorLike?--

Defaults to the origin.

) → CubicSpline

Cubic Bezier curves: points 1-4 make the first curve, 4-7 the second, and so on, so it passes through every third point. Points past the last complete curve are kept but ignored.

hermite​

</>
Splynx.hermite(
points: {VectorLike}?,--

Relative to the pivot.

velocities: {VectorLike}?,--

One per point. Missing ones are zero.

pivot: VectorLike?--

Defaults to the origin.

) → CubicSpline

Passes through every point, leaving each one with its velocity. Change velocities with CubicSpline:setVelocity.

cardinal​

</>
Splynx.cardinal(
points: {VectorLike}?,--

Relative to the pivot.

scale: number,--

How strongly the curve follows its neighbours; 0.5 is Catmull-Rom.

pivot: VectorLike?--

Defaults to the origin.

) → CubicSpline

Passes through every point, with velocities of (next - previous) * scale. The end points mirror their only neighbour. Change the scale with CubicSpline:setScale.

catmullRom​

</>
Splynx.catmullRom(
points: {VectorLike}?,--

Relative to the pivot.

pivot: VectorLike?--

Defaults to the origin.

) → CubicSpline

A Splynx.cardinal spline with a scale of 0.5: passes through every point with natural-looking curves.

bSpline​

</>
Splynx.bSpline(
points: {VectorLike}?,--

Relative to the pivot.

pivot: VectorLike?--

Defaults to the origin.

) → CubicSpline

A uniform cubic B-spline: smooth everywhere, including across joints, but it only passes near its points. Needs at least four points.

sampled​

</>
Splynx.sampled(
source: LinearSpline | CubicSpline,--

The spline to copy.

spacing: number--

Studs between samples, along the spline.

) → SampledSpline

A static copy of source as straight segments spacing studs apart along it, for the fastest distance lookups. Smaller spacing follows curves more closely. It doesn't follow later edits to source; sample it again after changing it.

TypeDescription
