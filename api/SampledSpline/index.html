SampledSpline

A static copy of a spline as straight segments a fixed distance apart along it, made by Splynx.sampled. Finding the segment for a distance is a single division instead of a search, which makes it the fastest spline for distance lookups.

Between samples it's a straight line, so it's off by about spacing^2 / (8 * radius) on a bend of that radius. Sharp corners get cut across by up to half the spacing.

It only knows distances, so alpha is always a fraction of the length: SampledSpline:getPos moves at a constant speed.
